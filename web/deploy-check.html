📱 Pasang PintarAI di HP

Android: buka PintarAI di Chrome lewat HTTPS, lalu gunakan menu ⋮ → Instal aplikasi / Tambahkan ke layar utama.

iPhone: buka PintarAI di Safari, pilih Bagikan → Tambahkan ke Layar Utama. Tampilan menu bisa bervariasi menurut versi iOS.

Komputer: browser yang mendukung PWA mungkin menampilkan ikon instal di bilah alamat.

Mode instal PWA tidak tersedia saat membuka file HTML biasa dari folder lokal; gunakan alamat HTTPS atau localhost. Ini masih demo, bukan APK di Play Store.
